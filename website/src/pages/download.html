This is the Apple silicon (M1 and later) version. On an older Intel Mac, download the Intel version.

Installing on Windows
  1. Open the downloaded Kertas-Office-Setup.exe.
  2. If Edge says the file isn't commonly downloaded, open the downloads list, click ⋯ next to the file, then Keep, Show more and Keep anyway. If Windows then says it protected your PC, click More info, then Run anyway. Why?
  3. Windows shows the publisher as SignPath Foundation. Click Yes.
  4. Choose a folder, or keep the default, and finish. No administrator rights are needed.
Installing on macOS
  1. Open the downloaded .dmg file.
  2. Drag Kertas Office into the Applications folder.
  3. Open it from Applications. macOS asks once whether to open an app downloaded from the internet; click Open.
Installing on Linux
  1. AppImage: make the file executable (right-click, Properties, Permissions), then double-click it.
  2. Ubuntu or Debian: open the .deb with your software centre, or run sudo apt install ./kertas-office-amd64.deb.
  3. Kertas appears in your applications menu under Office.

The Windows installer is signed by SignPath Foundation, which confirms it was built from the Kertas Office public repository. To check, right-click the file, open Properties, then Digital Signatures, or run:

Get-FileHash .\Kertas-Office-Setup.exe -Algorithm SHA256
Get-AuthenticodeSignature .\Kertas-Office-Setup.exe
