Changelog and roadmap

What shipped, what is being built now and what comes after. Plans change with feedback, so join the conversation on GitHub Discussions.

New in version 1.3

What's new

New Writer, Sheets and PDF editors, free for everyone. Kertas updates itself, or you can download it here.

WWriter

A smoother Writer

Typing, the cursor and selection feel faster and text looks sharper. Rulers on the top and side let you drag margins, indents and the header distance.

SSheets

A new Sheets

Charts, PivotTables, slicers, sparklines, conditional formatting and data validation, in a spreadsheet editor built for large workbooks.

PPDF

More you can do with a PDF

Edit text, add pictures and stamps, design forms and work with layers. The Convert tab turns a PDF into Word, Excel or pictures, reads scans and makes files smaller.

  • Compare documents and mail merge in Writer
  • Select, move and duplicate PDF annotations
  • Offline spelling in six languages
  • The previous editors stay one release, in About

Changelog From GitHub Releases

v1.3.0
Latest
Kertas Office 1.3.0

New Writer, Sheets and PDF editors: smoother typing and selection, and many more tools. The previous editors stay available for this release from About. Every change is listed on GitHub Releases.

WWriter

  • A new editor with smoother cursor, selection and text rendering
  • Rulers on the top and side, with draggable margins, indents and header distance
  • Compare documents, mail merge, citations, footnotes, captions, cross-references and track changes
  • Form fields, slash menu, equations edited with a double-click, and offline spelling in six languages

SSheets

  • A new spreadsheet editor with charts, pivot tables, slicers, sparklines and conditional formatting

PPDF

  • A new PDF editor: edit text, insert pictures and stamps, fill and design forms, and work with layers
  • Select mode to move, resize, reorder and delete annotations
  • Convert to Word and Excel, compress, text recognition, merge, sign and pictures to PDF
v1.2.3
Kertas Office 1.2.3

A fix for Find in Writer, and better PDF to Word conversion. Every change is listed on GitHub Releases.

WWriter

  • Find: typing a second word no longer goes into the document or freezes the app

PPDF

  • Convert to Word spots PDFs whose stored text is unreadable and offers to read the pages with text recognition instead
  • Converted documents keep one font size per paragraph instead of changing size from word to word
  • Paragraphs with wide line spacing convert as paragraphs, not one line each
v1.2.2
Kertas Office 1.2.2

A fix for editing equations. Every change is listed on GitHub Releases.

WWriter

  • An edited equation now shows its changes on the page straight away
v1.2.1
Kertas Office 1.2.1

Faster text recognition in PDF and editable equations in Writer. Every change is listed on GitHub Releases.

PPDF

  • Text recognition (OCR) is much faster, most of all for scans from phone and scanner apps, and reads several pages at once
  • Stop text recognition at any time, and see how long is left
  • Search finds recognised text straight away, without saving first

WWriter

  • Double-click an equation, or right-click it, to edit it, including equations made in Word
v1.2
Kertas Office 1.2

Compare versions of documents and PDFs, and refer to other parts of a document. Every change is listed on GitHub Releases.

WWriter

  • Compare two versions of a document: the differences open as tracked changes
  • Bookmarks, and cross-references to headings, captions and bookmarks that stay up to date
  • Ticks, boxes and arrows set in Wingdings and Symbol fonts are drawn correctly
  • Diagonal lines in table cells are drawn
  • A merged table cell taller than a page breaks across pages

PPDF

  • Compare two PDFs side by side, with every change listed and boxed
  • Drop files on the Files tab to attach them, or between page thumbnails to insert their pages
v1.1
Kertas Office 1.1

A feature release for all three apps. Every change is listed on GitHub Releases.

WWriter

  • Right-click menu with a formatting bar, plus Font and Paragraph dialogs
  • Table borders, shading, row height, cell margins and cell alignment
  • Pictures: rotate, flip, crop, change, caption and link, or drag them onto the page
  • Multilevel lists, custom numbering and a Tabs dialog
  • Different first, odd and even page headers and footers
  • Form fields: text, tick box, dropdown and date

SSheets

  • Threaded comments with replies, resolve and reopen
  • Named ranges from the Formulas tab or the right-click menu

PPDF

  • Attach any file to a PDF, then open, save or remove it from the Files tab

KFixes

  • Typing works again with two Writer documents open
  • Pictures and certificates picked in Open dialogs can be read again
  • Delete and Rotate in PDF act on the page just clicked
  • Recent files keeps every file opened at once, up to the last 10
v1.0
Kertas Office 1.0

The first stable release: Writer, Sheets and PDF in one window. Highlights below; every change is listed on GitHub Releases.

PPDF

  • Edit existing text by clicking a line and typing over it
  • Sign with a .p12 or .pfx certificate, or with a drawn signature
  • Text recognition (OCR) for scanned pages
  • Convert PDFs to Word and Excel
  • Fill and create forms, redact, protect with a password

WWriter

  • Track changes and comments, with replies and resolving
  • Equations typed in LaTeX, saved as native Word equations
  • Citations and bibliography in five styles
  • Mail merge from Excel or CSV
  • Eight ready-made templates

SSheets

  • Charts that update as the numbers change
  • PivotTables saved as genuine Excel pivots that refresh
  • Sparklines, slicers and conditional formatting
  • Eight ready-made templates
