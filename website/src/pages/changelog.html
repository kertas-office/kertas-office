Changelog From GitHub Releases

v1.0
Latest
Kertas Office 1.0

The first stable release: Writer, Sheets and PDF in one window. Highlights below; every change is listed on GitHub Releases.

PPDF

  • Edit existing text by clicking a line and typing over it
  • Sign with a .p12 or .pfx certificate, or with a drawn signature
  • Text recognition (OCR) for scanned pages
  • Convert PDFs to Word and Excel
  • Fill and create forms, redact, protect with a password

WWriter

  • Track changes and comments, with replies and resolving
  • Equations typed in LaTeX, saved as native Word equations
  • Citations and bibliography in five styles
  • Mail merge from Excel or CSV
  • Eight ready-made templates

SSheets

  • Charts that update as the numbers change
  • PivotTables saved as genuine Excel pivots that refresh
  • Sparklines, slicers and conditional formatting
  • Eight ready-made templates
Every version, with full notes and files, is on GitHub Releases.
