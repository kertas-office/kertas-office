Changelog and roadmap

What shipped, what is being built now and what comes after. Plans change with feedback, so join the conversation on GitHub Discussions.

New in version 1.1

What's new

A free update for everyone. Kertas checks for it on its own, or you can download it here.

WWriter

Format from the right-click menu

A formatting bar sits above the menu, with Font and Paragraph one click away. Tables get borders, shading, row height and cell alignment, and pictures rotate, flip and crop.

SSheets

Talk it through on the cell

Threaded comments with replies and resolve, saved so Excel, LibreOffice and WPS can read them. Named ranges make formulas read like plain words.

PPDF

Keep the files with the PDF

Attach a spreadsheet, a photo or any other file to a PDF, so everything travels together. Open, save or remove them from the Files tab.

  • Form fields: tick box, dropdown, date
  • Multilevel lists and custom numbering
  • Different first, odd and even page headers
  • Drag pictures straight onto the page

Changelog From GitHub Releases

v1.1
Latest
Kertas Office 1.1

A feature release for all three apps. Every change is listed on GitHub Releases.

WWriter

  • Right-click menu with a formatting bar, plus Font and Paragraph dialogs
  • Table borders, shading, row height, cell margins and cell alignment
  • Pictures: rotate, flip, crop, change, caption and link, or drag them onto the page
  • Multilevel lists, custom numbering and a Tabs dialog
  • Different first, odd and even page headers and footers
  • Form fields: text, tick box, dropdown and date

SSheets

  • Threaded comments with replies, resolve and reopen
  • Named ranges from the Formulas tab or the right-click menu

PPDF

  • Attach any file to a PDF, then open, save or remove it from the Files tab

KFixes

  • Typing works again with two Writer documents open
  • Pictures and certificates picked in Open dialogs can be read again
  • Delete and Rotate in PDF act on the page just clicked
  • Recent files keeps every file opened at once, up to the last 10
v1.0
Kertas Office 1.0

The first stable release: Writer, Sheets and PDF in one window. Highlights below; every change is listed on GitHub Releases.

PPDF

  • Edit existing text by clicking a line and typing over it
  • Sign with a .p12 or .pfx certificate, or with a drawn signature
  • Text recognition (OCR) for scanned pages
  • Convert PDFs to Word and Excel
  • Fill and create forms, redact, protect with a password

WWriter

  • Track changes and comments, with replies and resolving
  • Equations typed in LaTeX, saved as native Word equations
  • Citations and bibliography in five styles
  • Mail merge from Excel or CSV
  • Eight ready-made templates

SSheets

  • Charts that update as the numbers change
  • PivotTables saved as genuine Excel pivots that refresh
  • Sparklines, slicers and conditional formatting
  • Eight ready-made templates
Every version, with full notes and files, is on GitHub Releases.
