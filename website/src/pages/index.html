One workspace for the documents you create, edit and manage every day.

Where Kertas comes from

Started by one person. Now built by its community.

Kertas, Malay for paper, began as a solo side project with a simple idea: a good office suite should not come with ads, accounts or a paid tier. With version 1.0 it became an open project that anyone can use, inspect and improve.

01 · The idea
A solo project

Built to answer a frustration many people share: free office apps that nag, upsell or upload your files.

02 · Version 1.0
Released in the open

Questions

Why is it free?

Kertas is built on open-source engines and released the same way. It is supported by its users, not by your data or a paid tier.

Will my Word and Excel files look the same?

Kertas saves in the native .docx and .xlsx formats, and most documents round-trip cleanly. Very complex layouts may shift slightly. The compatibility page lists exactly what is partial.

Who makes Kertas?

Kertas started as a solo project and is now developed in the open by its contributors. Anyone can join on GitHub. It is not run by a company.

Is it safe to install?

Every installer is built automatically by GitHub Actions from the public source code, so what you download matches what anyone can read. Code signing for Windows is being set up, so for now Windows may show an "unrecognised app" warning the first time. Here is what to do.Windows installers are signed through SignPath Foundation. Read our code signing policy.

Does it include presentations?

No. Kertas focuses on documents, spreadsheets and PDFs, and aims to do those three very well.

Can I use Kertas at work?

Yes, for business, school and government use alike, at no cost. The AGPL licence only adds obligations for people who modify Kertas and distribute it or run it as a service.
